# Murderface Three

Part of an ongoing experiment for seeing how we can use documentation to improve
"AI enablement" for the BCGov design system. See: https://github.com/bcgov/design-system/

In this iteration, we were given our chosen, limited scope of Github CoPilot, to
execute on a plan in order to see how well it leveraged our "robot documentation."

This thing runs like any NPM react application, so you need only install the
dependencies with `npm i` and run `npm run dev` to see it.

## Tools Used:

- Github CoPilot CLI on Fedora Linux with no priviliged subscription
- Claude Haiku 4.5, as chosen by CoPilot
- A [mock up](./murderface-three.png) and a [plan](./plan.md)
