# The Plan

Using ./murderface-three.png and the BC Government Design System, build a React
SPA that utilizes the design system as much as possible. The context is a "cat
registration profile page".

The design system is https://github.com/bcgov/design-system, where you can find
details about where to find the react components and design tokens libraries.
Use vite.

Take care to read the design system depenedencies, both the tokens and the
components have an AGENTS.md in their dist folders that provide guidance for
implementing the design system. Be sure to use the `next` tag when installing
the dependencies so that you get the documentation.

Should the mockup deviate from our standards for design, trust the standards
instead.

Create an AGENTS.md for further development that protect the use of the upstream
design system standards
